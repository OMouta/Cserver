Cserver

A minimal Win32 HTTP server (MSYS2 / MinGW) — serves static files, small thread pool, basic CGI & simple log rotation.

Docs

Highlights

  • Serve a directory of static files (default public).
  • Small configurable thread pool.
  • Access logs in Combined Log Format with size-based rotation.
  • Basic per-request CGI support (php-cgi or other interpreters).

Quick build (CMake + MinGW)

cmake --preset mingw
cmake --build --preset release

Run examples

Default (serve public on port 8080):

.\build\Cserver.exe

Serve with logs and 4 workers:

.\build\Cserver.exe --port 8080 --serve public --workers 4 --log-file .\server.log

Rotate logs at ~10 MB, keep 5 files:

.\build\Cserver.exe --log-file .\server.log --log-rotate-size 10M --log-rotate-count 5

Common flags

  • --port <port> — listen port (default 8080)
  • --serve <path> — directory to serve (default public)
  • --workers <N> — number of worker threads (default 8)
  • --log-file <path>, --log-rotate-size <size>, --log-rotate-count <n>
  • --php-cgi <path> — path to php-cgi to enable executing .php files

Notes & limitations

  • No TLS — put behind a reverse proxy for production.
  • Minimal HTTP parsing and CGI is per-request process (simple, not high-performance).
  • Log rotation is rename-based; no compression or time-based features.

Build

The project builds with CMake (recommended) or directly with gcc/MSYS2. A `CMakePresets.json` includes a `mingw` preset.

Recommended (CMake + MinGW):

cmake --preset mingw
cmake --build --preset release

Or manually:

cmake -S . -B build -G "MinGW Makefiles"
cmake --build build --config Release

PowerShell helper:

.\scripts\build.ps1

Run

After building the executable will live under build\ (named Cserver.exe when built on Windows).

.\build\Cserver.exe

Examples:

.\build\Cserver.exe --port 8080 --serve public --workers 4 --log-file .\server.log
.\build\Cserver.exe --log-file .\server.log --log-rotate-size 10M --log-rotate-count 5

Command-line flags

  • --port <port> — TCP port to listen on (default 8080).
  • --serve <path> — directory to serve (default public); --public also accepted.
  • --workers <N> — number of worker threads (default 8).
  • --log-file <path> — append access and internal logs to the provided file.
  • --log-rotate-size <size> — enable size-based rotation; examples: 1K, 10M, 1G.
  • --log-rotate-count <n> — how many rotated files to keep (default 5).
  • --php-cgi <path> — path to a php-cgi executable to execute .php files (default php-cgi).

Logging (Combined Log Format)

When --log-file is used access logs are written in Combined Log Format (CLF):

%h %l %u [%t] "%r" %>s %b "%{Referer}i" "%{User-agent}i"

Example:

127.0.0.1 - - [17/Aug/2025:00:35:10 +0000] "GET /index.html HTTP/1.1" 200 1024 "-" "curl/7.68.0"

Limitations & security notes

  • No TLS — use a reverse proxy (nginx, Caddy) or TLS-terminating load balancer for production.
  • Minimal HTTP parsing; only basic GET is implemented and many headers/edge-cases are not fully RFC-compliant.
  • No rate limiting or per-IP connection limits.
  • Log rotation is simple rename-based; no compression or time-based rotation.
  • CGI spawns an interpreter process per-request (CreateProcess). For production PHP use a FastCGI backend.

Files of interest

  • src/server.c — server entrypoint and argument parsing
  • src/http.c / src/http.h — HTTP parsing & static file serving
  • src/log.c / src/log.h — logging and rotation
  • src/threadpool.c / src/threadpool.h — worker queue and threads
  • src/cgi.c / src/cgi.h — CGI handling

Scripts

Helper scripts for Windows are provided under scripts/:

  • scripts/build.ps1 — PowerShell helper to configure and build with CMake.
  • scripts/start.ps1 — PowerShell helper to start the built binary with convenient presets (flags: -WithPhp, -WithLogs, etc.).
  • Equivalent .bat helpers are also present for cmd.exe.
